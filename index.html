A note about this beta

Mac builds are ad-hoc signed and aren’t notarized yet. Windows builds are unsigned. Your system may block the app or show a security prompt. Follow your organization’s security policy; don’t disable system protections.

Not sure which Mac? Open Apple menu → About This Mac: “Chip” means Apple Silicon; “Processor: Intel” means Intel.

FROM DOWNLOAD TO FIRST REVIEW

Make yourself at home.

The app’s Connections screen guides you through setup. Your history stays on your computer; your accounts stay with the official CLIs.

Read the full getting-started guide ↗

  1. Extract and open

    On Mac, open Review Desk. On Windows, extract the entire ZIP and keep the runtime files beside Review Desk.exe.

  2. Connect Claude and GitHub

    Install the required tools from Connections, then sign in using the official Claude Code and GitHub CLI flows. Reviews use your Claude subscription and share its limits.

  3. Bring your first PR

    Paste a GitHub PR URL, choose your team and instructions, then start the review. You can inspect comments before posting them.
